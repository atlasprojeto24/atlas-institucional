## Estrutura
- `index.html`: página inicial
- `digital/` e `design/`: unidades abertas
- `consulting/`, `venture/`, `software/`: páginas Em breve
- `insights/`: hub editorial
- `fundador/`: página de apresentação do fundador
- `contato/`: contato
- `assets/`: CSS, JavaScript e identidade visual
